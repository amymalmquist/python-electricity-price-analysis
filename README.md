# python-electricity-price-analysis
## About the project

This project is a Python program for working with and analysing electricity price data.

The program contains electricity price information for different years, months, electricity areas (SE1–SE4), and different types of electricity contracts. The data is divided between apartments and houses.

The user can interact with the program through different input options and choose what information they want to display or analyse.

## Features 
- Display electricity price data
- Display data in different formats
- Choose between apartment and house
- Select different electricity areas (SE1–SE4)
- Work with different contract types
- Calculate average electricity prices
- Find the highest electricity price
- Find which month had the highest electricity price
- User interaction through input menus

## What I learned

Through this project, I practised working with Python, lists, user input, conditional statements, calculations and data analysis.
